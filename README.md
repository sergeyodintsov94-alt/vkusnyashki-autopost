# Автопубликация @vkusnyashki_uk

42 поста на 3 недели (20.10–09.11.2026): по 2 в день, в 12:00 и 19:00 по Алматы,
по воскресеньям в 19:00 — Reels. Очередь лежит в `queue.json`, публикует `publish.py`
через официальный Instagram Graph API. Запускает его GitHub каждые 15 минут, компьютер включённым держать не нужно.

## Настройка (один раз, около 30–40 минут)

### 1. Instagram
- Аккаунт должен быть **профессиональным** (Business или Creator) и привязан к странице Facebook.
- На https://developers.facebook.com создайте приложение (тип Business), добавьте продукт Instagram.
- Права: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`.
- Получите **долгоживущий токен страницы** (Page access token из долгоживущего пользовательского токена —
  такой токен не истекает) и **IG User ID** (в Graph API Explorer: `me/accounts?fields=instagram_business_account`).

### 2. GitHub
- Создайте **публичный** репозиторий и загрузите в него всё содержимое этой папки.
  Публичный нужен, потому что Instagram скачивает картинки и видео по ссылке. Эти же картинки и цены
  и так будут видны всем в Instagram.
- Settings → Secrets and variables → Actions → New repository secret: `IG_USER_ID` и `IG_ACCESS_TOKEN`.
- Вкладка Actions → включите workflows → «Публикация в Instagram» → Run workflow → команда `check`.
  Если в логе написан ник аккаунта, всё подключено.

## Как это работает
- Раз в 15 минут запускается `python publish.py run`: берёт посты, время которых наступило, публикует (не больше 3 за запуск) и
  записывает статус в `queue.json`.
- GitHub иногда запускает задачи с опозданием на 5–30 минут — это нормально.
- Пост, просроченный больше чем на 12 часов (например, при остановке), автоматически не публикуется и получает статус `missed`.
- Ошибка одного поста не останавливает остальные: статус `failed` и текст ошибки в `queue.json`.

## Управление
| Что нужно | Команда |
|---|---|
| Посмотреть очередь | `python publish.py list` |
| Проверить подключение | `python publish.py check` |
| Пауза | создать пустой файл `PAUSED` в корне репозитория; чтобы продолжить, удалить |
| Опубликовать пост сейчас | `python publish.py now 05_volzhskie` |
| Повторить failed/missed | `python publish.py retry 05_volzhskie` |
| Добавить пост | `python publish.py add output/posts/new.jpg --at "2026-11-10 12:00"` (подпись в `new.txt` рядом) |
| Разблокировать после замены фото | `python publish.py unlock 34_mokko` |

Посты 34, 38 и 42 (Мокко, Брауни, Абрикос) имеют статус `needs_photo`: фото товара не было, поэтому
автоматически они не выходят. Пришлите фото — картинку заменят, и пост разблокируется командой `unlock`.

## Ограничения и важное
- Токен: если используете токен Instagram Login (а не токен страницы Facebook), он живёт 60 дней и его нужно обновлять,
  иначе публикация остановится с ошибкой «код 190».
- Instagram позволяет не больше 100 публикаций через API в сутки — у нас 2.
- Reels публикуется как видео 1080x1920 до 90 секунд; наши — по 23 секунды.
- Запуск на своём компьютере вместо GitHub: `run_local.sh` + cron (Mac/Linux) или Планировщик заданий (Windows), настройки в `.env`.
- Скрипт проверен на очереди и расписании, но не на вашем реальном аккаунте (токенов у нас нет): первый запуск `check` обязателен.
